# 健身房器材识别与用法

用户拍一张器材照片时用这份表。**先给候选，再让他确认，最后讲用法**——不要看一眼就下结论。

## 识别流程

1. **看特征**：把手方向、座椅形状、配重方式（插销 / 杠铃片 / 绳索）、轨迹（推 / 拉 / 夹 / 蹬）
2. **给 2–3 个候选**：「这看起来像坐姿推胸机，也可能是蝴蝶机夹胸，你看一下机器上的图示/铭牌写的是什么？」
3. **确认后再讲**：练什么、怎么调、怎么做、常见错误
4. **不确定就说不知道**：拍不清铭牌、只拍到一角、被挡住，直接说"看不准，拍一张带铭牌的"

## 常见器材

### 坐姿推胸机（Chest Press）

- **练什么**：胸大肌为主，肱三头肌、三角肌前束协同
- **怎么调**：座椅高度让把手与**乳头连线**齐平；背垫贴紧，脚踩实
- **要点**：肩胛后缩下沉再推；肘约 45°，不要完全锁死
- **易错**：肩前顶、耸肩、推到手臂完全伸直
- **替代**：哑铃卧推、俯卧撑

### 蝴蝶机 / 夹胸（Pec Deck）

- **练什么**：胸大肌（内侧收缩感强）
- **怎么调**：座椅让把手与肩同高；手臂微屈固定
- **要点**：用胸把手臂"抱"向中线，顶峰停 1 秒
- **易错**：用肩发力、肘角度变化、回放太快
- **替代**：绳索夹胸、哑铃飞鸟

### 高位下拉（Lat Pulldown）

- **练什么**：背阔肌为主，肱二头肌、中斜方协同
- **怎么调**：大腿垫压紧；握距略宽于肩
- **要点**：胸口抬起、肘向下沉、拉到锁骨附近
- **易错**：身体大幅后仰、拉到颈后、耸肩
- **替代**：引体向上、弹力带下拉

### 坐姿划船（Seated Row）

- **练什么**：背阔肌、菱形肌、中斜方
- **怎么调**：脚踩踏板、膝微屈；把手与胸下沿齐平
- **要点**：先沉肩再拉，肘贴身向后，肩胛夹紧
- **易错**：用腰后仰借力、耸肩、只用手臂
- **替代**：哑铃单臂划船、弹力带划船

### 腿举机（Leg Press）

- **练什么**：股四头肌、臀大肌
- **怎么调**：座椅让膝盖起始约 90°；脚踩踏板与肩同宽
- **要点**：下放到膝盖约 90° 就推起，膝盖跟脚尖同向
- **易错**：下放过深让腰离垫、膝内扣、锁死膝盖
- **替代**：高脚杯深蹲、靠墙静蹲

### 腿屈伸（Leg Extension）

- **练什么**：股四头肌（孤立）
- **怎么调**：膝关节对准机器转轴；脚踝垫在脚背上方
- **要点**：匀速伸直到接近伸直，顶峰停 1 秒
- **易错**：甩腿、重量过大、膝盖有痛还硬做
- **注意**：膝痛者慎用或换小幅度
- **替代**：靠墙静蹲

### 腿弯举（Leg Curl）

- **练什么**：腘绳肌
- **怎么调**：转轴对准膝关节；垫子贴住脚踝后侧
- **要点**：匀速屈膝，不要让髋抬起
- **易错**：用腰把髋顶起来、回放失控
- **替代**：臀桥、罗马尼亚硬拉

### 史密斯机（Smith Machine）

- **练什么**：看你怎么用——深蹲、推举、划船都能做
- **怎么调**：安全销设在最低点略高于你失败的位置；杠在锁骨/斜方上
- **要点**：轨迹固定，脚的位置要配合杠的路径
- **易错**：以为固定轨迹就不用控制、安全销没设
- **替代**：自由重量（需要保护者）

### 龙门架 / 绳索（Cable Machine）

- **练什么**：几乎全能——夹胸、下拉、面拉、下压、弯举
- **怎么调**：滑轮高度决定动作（高→下拉/下压；中→夹胸/面拉；低→弯举/上拉）
- **要点**：先调高度再选重量，绳索要保持张力
- **易错**：滑轮高度不对、身体跟着晃
- **替代**：弹力带（居家版）

### 髋外展机（Hip Abduction）

- **练什么**：臀中肌
- **怎么调**：坐稳，膝垫贴大腿外侧
- **要点**：用臀外侧把腿打开，慢开慢回
- **易错**：身体前倾借力、弹震
- **替代**：蚌式、侧卧抬腿

### 提踵机（Calf Raise）

- **练什么**：小腿三头肌
- **怎么调**：肩垫压在斜方，前脚掌踩踏板边缘
- **要点**：下放到脚跟低于踏板，再顶到最高点停 1 秒
- **易错**：弹震、幅度太小
- **替代**：站姿提踵

### 跑步机 / 椭圆机 / 划船机

- **练什么**：心肺为主
- **怎么调**：跑步机先走 3 分钟再加速；划船机阻力 3–5 档起步
- **要点**：能说话但不能唱歌的强度（RPE 4–5）
- **易错**：一上来就冲、扶把手跑步

## 回答模板

> 这台看起来像**坐姿推胸机**（也可能是蝴蝶机，你看下机器上的图示）。
>
> 如果确认是推胸机：
> - 练：胸大肌为主，三头协同
> - 调：座椅调到把手与乳头齐平，背贴紧
> - 做：肩胛后缩 → 推出去 → 控制回
> - 别：耸肩、锁死肘、用腰顶
>
> 不确定的话拍一张带铭牌的照片，我再确认。

## 边界

- **不做器械安全的最终判断**：机器有故障、配重销缺失、钢缆磨损，直接让用户找场馆工作人员
- **不教自由重量大重量动作的保护技巧**：深蹲、卧推、硬拉的极限重量需要现场保护者
- **孕妇、术后、心血管问题**：先按 `safety.md` 走红旗流程，不直接教器械
